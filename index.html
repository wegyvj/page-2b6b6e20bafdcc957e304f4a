快柠檬

快柠檬把机场订阅、VPN 梯子与多端加速器拆成可执行的步骤：先选套餐拿到订阅，再按设备选择客户端并导入。本页是官网说明，重点讲清「客户端怎么选」，而不是把你锁进某一个壳程序。

品牌简介

快柠檬是面向个人与小团队的机场订阅服务。开通后你会得到一条订阅链接，把它放进自己常用的代理客户端，即可按规则访问境外站点、处理跨境办公流量，或在支持的套餐下观看流媒体。服务形态是「订阅 + 自选客户端」，而不是单一 App 包办一切。

这样设计的原因很直接：Windows、macOS、iOS、Android 上成熟的加速器并不相同，强行统一安装包往往牺牲稳定与更新节奏。快柠檬只负责机场侧的订阅与套餐，客户端交给各系统里更合适的工具。只要订阅格式被客户端识别，同一条链接可以在多台设备上复用，同时在线数量以套餐说明为准。

如果你第一次接触机场，不必先研究协议名词。按本页纵向步骤走完「开通 → 复制订阅 → 选客户端 → 导入更新 → 连接切换」，就能完成第一次可用配置。遇到问题再看文末问答。

适用场景

跨境协作与远程会议

文档、代码托管、设计稿与会议软件分布在不同地区时，本地运营商路由可能绕远或被干扰。把系统代理或分应用代理交给客户端，只加速需要出境的流量，办公软件仍走原来的习惯。

资料检索与开发调试

学术页面、公开数据库、语言文档和软件发行页经常因地区策略打不开。用规则模式访问这些站点，避免把国内银行、政务类 App 一并送进代理。

流媒体与内容浏览

部分套餐会标注流媒体相关能力。实际能否播放还取决于节点地区、客户端规则以及浏览器自身缓存。打不开时先换节点、清站点 cookies，再检查是否误用了旧规则集。

多设备共用同一订阅

手机出门、电脑在工位，是机场用户的典型组合。同一订阅可导入多端，但请在不用的设备上断开，以免占满同时在线名额。团队场景把设备数作为选套餐的第一指标。

从开通到连接的五步

下面按真实使用顺序排列。第三步「选择客户端」决定后续体感，请不要跳过。

1确认需求并开通套餐

先数清要同时在线的设备，再估计每月流量习惯。浏览、会议、视频的消耗差一个数量级，选错档位只会反复升级。开通入口见本页套餐区，权益与价格以该模块为准，正文不重复报价。

2在用户中心复制订阅

订阅链接是客户端拉取节点与规则的钥匙。只在可信任的网络环境下复制，不要发到公开群、网盘或截图。若链接含访问密钥，泄露等于把套餐借给他人。

3按设备选择客户端

这是快柠檬使用体验的分界点。同一份机场订阅可以进 Clash 系、Shadowrocket、v2rayN 或 sing-box，但系统匹配错了会出现无法接管流量、耗电异常或更新失败。先锁定主力设备，对照下一节平台说明再下载。

4导入订阅并更新列表

打开客户端的订阅或配置页，粘贴链接，执行更新。看到节点分组后再连接。列表为空时，优先检查链接是否被截断、客户端是否支持该订阅类型，而不是反复重装。

5连接、分流与切换

日常用规则模式：国内直连、境外走代理。某个站点异常就换节点，不必重装客户端。游戏或会议若对线路类型有要求，到套餐说明里核对是否包含对应优化，再在客户端里指定分组。

如何选择客户端

快柠檬不绑定单一加速器。选客户端时只看四件事：系统是否长期维护、能否导入通用订阅、规则更新是否方便、后台是否稳定。下面按平台给出常用方向，下载入口集中在后文模块，本页不另写第三方安装地址。

Windows

图形界面优先考虑 Clash 系客户端（如 Clash Verge 一类），系统代理开关和规则分组比较直观。习惯手动选核心、自己改路由的人可以用 v2rayN。不要同时开两个会抢系统代理的程序，否则浏览器显示「已连接」但实际流量混乱。

macOS

需要菜单栏常驻、一键接管系统代理时，ClashX 或同系工具足够日常办公。对规则、策略组、脚本有更高要求可考虑 Surge（商店付费）。公司电脑若限制安装来源，先确认能否从官方渠道获取，再导入快柠檬订阅。

iOS

常见选择是 Shadowrocket、Stash、Quantumult X。能否买到取决于 Apple ID 地区，以你所在区商店实际货架为准。首次导入后系统会请求 VPN 配置权限，必须允许，否则只有「节点列表」没有实际加速。蜂窝网络下注意低数据模式可能暂停隧道。

Android

Clash Meta 系与 Surfboard 等都能导入订阅。安卓的省电策略会误杀后台，需在系统设置里允许自启动、关闭对该应用的电池优化，否则锁屏后梯子掉线。分应用代理适合只加速浏览器或视频 App 的人。

Linux 与其它环境

命令行用户可使用 clash / mihomo / sing-box 等核心，把订阅转为本地配置后配合系统服务运行。需要图形界面再用 Clash Verge。路由器或 NAS 属于进阶用法，先保证手机和电脑跑通，再考虑旁路网关。

选择时的几条硬原则

  • 主力系统先定一个客户端，其它设备再扩展，避免规则口径不一致。
  • 同一快柠檬订阅可多端导入，同时在线数量受套餐限制。
  • 同一台设备不要并行开启多个系统代理。
  • 更新订阅之后再判断「有没有节点」，不要先卸载重装。
  • 只从本页下载模块或应用商店获取客户端，避开来路不明的修改包，以免订阅被抽走。

常见问题

快柠檬是什么？和普通 VPN 有何不同？

快柠檬是机场订阅型网络加速服务。你购买的是可导入多款客户端的订阅，而不是只能打开某一个 VPN 商标的 App。节点、规则、分流都在你选择的加速器里完成，适合已经有客户端使用习惯、或需要电脑手机分开配置的人。

必须使用指定客户端吗？

没有唯一指定。只要客户端支持常见订阅与代理协议，就能导入同一条快柠檬链接。建议按操作系统挑选维护活跃、你自己看得懂界面的工具，并对照本页「如何选择客户端」。不要同时运行两个抢系统代理的程序。

第一次应该按什么顺序操作？

开通套餐、复制订阅、按设备下载客户端、在客户端里导入并更新、选择节点连接。这五步不要颠倒。列表空白时先检查订阅是否完整、客户端类型是否匹配，再尝试手动更新，而不是反复注册新账号。

手机和电脑可以一起在线吗？

可以导入同一订阅。同时在线数量取决于套餐，超出后新设备可能无法认证。会议结束或离开工位时在客户端里断开，就能释放名额。团队如果设备很多，直接看更高档的设备上限，不要靠反复上下线硬挤。

客户端下载不到或提示不安全怎么办？

优先使用本页「客户端下载」模块。iOS 应用以 App Store 当前地区为准；桌面端请认准项目自己的发布渠道。快柠檬提供订阅，并不把第三方加速器改成「官方马甲包」。网盘里的破解版会读取你的订阅，造成套餐被盗用。

能看流媒体吗？提示地区不对怎么处理？

能否解锁以你所购套餐的说明为准，并不是所有档位都面向流媒体。若套餐支持但仍失败，先换对应地区节点，清掉网站 cookies，确认客户端处于规则或全局中的正确模式。浏览器插件、系统 VPN 与客户端叠加时，也容易让站点判定异常。

显示已连接但网页很慢或打不开？

先区分是「完全无网」还是「个别站点慢」。前者检查系统代理是否被其它软件占用、DNS 是否异常；后者直接换节点。本地宽带、运营商路由、目标站都在链路上，单次测速不能代表整天质量。规则模式把国内流量直连，通常比全局更稳。
